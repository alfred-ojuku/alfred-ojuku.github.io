# Personal Portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript.

## Customize

1. Replace every instance of `Your Name`, `YN`, `yourusername`, and `hello@example.com` in `index.html`.
2. Update the About, Projects, and Skills content with your information.
3. Replace each project `#` link with a real live-demo or source-code URL.
4. Add your profile photo to `assets/personal/` and your screenshots or project covers to `assets/projects/`.

## Image folders

```text
assets/
├── personal/   # Profile photo and personal images
└── projects/   # Project screenshots and cover images
```

## Preview

Open `index.html` directly, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

Push these files to a GitHub repository, then enable Pages under **Settings → Pages** using the repository's main branch.
