# Project images

Add screenshots, cover images, and project mockups here.

The portfolio currently looks for these filenames:

```text
business-central-data-exporter.webp
roamcore-api.webp
hermes.webp
dynamics-bigquery-etl.webp
```

Add images using those names and they will appear automatically. Until then,
each card displays its numbered color placeholder. WebP images around
1200 × 900 pixels are recommended.
